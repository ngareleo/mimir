# Network and GraphQL

This folder documents how the client talks to the server. The dominant surface is GraphQL through Ferry against an SDL generated by the server. A small list of REST endpoints exists for things GraphQL cannot do (OAuth callbacks, password-reset landing, health, metrics). The W3C `traceparent` header is the cross-stack correlator.
