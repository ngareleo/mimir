# Use cases

This folder covers the primary user journeys in Mimir — the paths a student takes when they create, share, or moderate a resource. The journeys here are reference-level descriptions of intent and flow, not screen-by-screen walkthroughs (those live in `docs/design/`).

## Contents

- `docs/product/04-use-cases/00-overview.md` — the two top-level journeys (creating personal resources, sharing them) and how the other use cases sit underneath.
- `docs/product/04-use-cases/01-creating-resources.md` — a student creating a personal timetable, semester, or academic item.
- `docs/product/04-use-cases/02-sharing-resources.md` — an owner sharing a resource and the recipient accepting it.
- `docs/product/04-use-cases/03-approving-changes.md` — the approval flow when a non-owner edits a shared resource.
- `docs/product/04-use-cases/04-moderation.md` — admin actions: appointing moderators, removing members, deleting shared resources.
